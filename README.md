One original fortune-cookie line for a software developer, written by `main.py` to `/output/entry.txt`.

## The entry (101 characters)

> The legacy code you curse was once someone's clever shortcut; treat it gently, for your code is next.

## Why this line — measured against the judge's brief, in its own order

1. **It is a fortune-cookie line for a developer** — not a slogan, punchline or generic advice. It speaks as a fortune would: a small truth handed to the reader, not an instruction.
2. **One short balanced sentence, one breath** — two clauses joined by a semicolon, 101 of the allowed 120 characters, no filler.
3. **True about a developer's day** — legacy code, named in the brief alongside bugs, reviews, deploys and estimates. Every developer has cursed code they did not write.
4. **An original turn, not a familiar saying** — "the code you curse was once someone's clever shortcut" is not a proverb being repeated; it reframes the curse as sympathy for the stranger who wrote it under pressure.
5. **A quiet twist rewarding a second read** — "for your code is next" carries two meanings at once: your code is next to become legacy, and next to be cursed by the engineer who follows you. The reader is both the curser and the cursed.

Seven candidate lines were drafted and scored against the five criteria above; this one won on criteria 4 and 5 — the two where most entries lose, because familiar sayings and one-meaning lines are what the judge has already heard.

## Run it

```
python3 main.py
```

Writes the line to `/output/entry.txt`. No network, no randomness, no input: the same line every run. Verified locally: 101 characters, UTF-8, single line, not only whitespace — inside the gate (1–120 characters).
